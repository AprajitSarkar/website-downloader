# Privacy Policy for Website Downloader

**Effective Date:** September 14, 2026

**Website Downloader** is committed to protecting your privacy. This Privacy Policy explains our data practices for the Website Downloader mobile application.

## 1. 100% On-Device Processing
All scraping, bundling, HTML/CSS/JS parsing, and website rendering operations take place **100% locally on your Android device**. No external servers, proxy servers, or third-party cloud services are used.

## 2. Zero Data Collection & Telemetry
- **No Data Collected:** We do not collect, track, store, or transmit any personal information, browsing history, downloaded URLs, or usage metrics.
- **No Analytics:** The app contains zero analytics, tracking scripts, or advertisement SDKs.
- **No Third-Party Transmission:** Downloaded websites and resources remain strictly within your device's local storage.

## 3. Storage Permissions
The application requests access to Scoped Storage on Android solely to save downloaded website ZIP packages to the local `Download/Website Downloader` directory so you can access your saved files.

## 4. Localhost Web Server
Website Downloader runs a local web server bound strictly to loopback interface `127.0.0.1`. This server is accessible only from your local device to serve downloaded offline files to the embedded browser WebView.
