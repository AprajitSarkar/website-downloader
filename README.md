## Overview
**Website Downloader** is a high-performance Android mobile application built with Flutter that scrapes, bundles, and renders complete websites entirely offline without requiring any external backend server.

## Key Features
- **100% Standalone On-Device Engine**: No Node.js backend required.
- **Embedded Localhost Web Server**: Serves downloaded websites over `127.0.0.1` loopback with full JS, CSS, and fonts.
- **Dynamic Download History**: Quick-access history chips below address bar.
- **ZIP Packaging & Scoped Storage**: Stored in `Download/Website Downloader`.
- **Live Terminal Console**: Real-time 4-stage pipeline metrics.
- **Liquid Glass UI**: Modern dark mode glassmorphism.
- **Zero Telemetry & 100% Private**: All data stays on your phone.
